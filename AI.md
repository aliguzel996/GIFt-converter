# GIFt-Converter

This project is a free open-source creative tool for batch video-to-GIF conversion without timeline editing, keyframing, or a giant post-production stack.

## What this tool is

GIFt-Converter is a small YCSWU tool with two faces:

- a native Windows desktop app
- a browser-based web build

Both are meant to do the same basic job: take one or more video files, convert them to GIFs, and let the user save the results directly or bundle them into ZIP files.

## Who it is for

- artists
- designers
- motion people
- anyone who needs quick GIF exports from short video files

It is not aimed at editors who want a timeline, effects stack, audio tools, or a larger video workflow.

## What problem it solves

It removes the repetitive part of making GIFs from multiple video files. The user can queue files, set FPS, choose a render mode, export, then save a GIF or ZIP without opening a full editing suite.

## What it can do

- batch video import
- per-file selection
- per-file FPS values
- bulk FPS apply
- GIF export
- render mode switching
- optional GIF optimization
- ZIP creation for completed GIF outputs
- Windows desktop packaging
- browser-based conversion in the web build

## What it cannot do

- timeline editing
- trimming and sequencing
- audio processing
- motion graphics compositing
- cloud rendering
